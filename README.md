# بات گزارش روزانه کارگاه ساختمانی

## قابلیت‌های جدید

### سرپرست
- ثبت گزارش + **گزارش سریع برای هر پروژه**
- ویرایش آخرین گزارش
- مشاهده گزارش‌های خود

### مدیر
- **گزارش امروز / این هفته** (خلاصه آماری، نه لیست بلند)
- **آمار و خلاصه**: ساعات کار، تنخواه، غذا، پروژه‌های بدون گزارش
- **فیلتر** بر اساس پروژه / تاریخ / سرپرست
- **ویرایش** هر گزارش با شماره
- **حذف با تأیید** (نمایش خلاصه قبل از حذف)
- **خروجی اکسل** و **PDF** (یک گزارش / بازه تاریخ / همه)
- **مدیریت کاربران** از داخل بات (افزودن، ویرایش نقش/پروژه، حذف)
- **لاگ فعالیت‌ها**
- **یادآوری خودکار** ساعت ۱۸ برای سرپرست‌هایی که گزارش نداده‌اند

### فنی
- ذخیره فایل‌های عکس/فیلم روی دیسک (`media_files/`) علاوه بر `file_id`
- PDF با فونت فارسی در صورت قرار دادن Vazirmatn در پوشه `fonts/`
- توکن فقط از `.env` خوانده می‌شود

## نصب

```bash
pip install -r requirements.txt
cp .env.example .env   # و توکن را بگذارید
python bot.py
```

### فونت PDF
فایل‌های `Vazirmatn-Regular.ttf` و در صورت تمایل `Vazirmatn-Bold.ttf` را در `fonts/` قرار دهید.
دانلود: https://github.com/rastikerdar/vazirmatn/releases

### Railway
- Volume را به `/data` وصل کنید تا دیتابیس و رسانه‌ها پایدار بمانند.
- `Procfile` از قبل آماده است.
